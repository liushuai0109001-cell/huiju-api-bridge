荟聚 API 外接软件 v1.0.10

一、首次使用
1. 双击“荟聚API外接软件.exe”。
2. 打开“授权管理”页，点击“复制机器码”，将机器码发送给软件提供方。
3. 收到授权码后粘贴到授权码输入框，点击“激活授权”。
4. 语言、图片、视频接口地址已固定为 https://huiju.v888.art，图床固定为 https://huiju.v888.art/upload；用户只填写 API Key。
5. 点击“获取模型”，从下拉框选择模型，然后保存配置。
6. 从外接软件点击“启动洛水”。

二、视频时长
- 15 秒（外接软件优先）：无论洛水请求什么时长，最终向中转站发送 15 秒。
- 30 秒（外接软件优先）：无论洛水请求什么时长，最终向中转站发送 30 秒。
- 视频最终时长始终以外接软件的 UI 选项为准。

三、授权说明
- 授权与当前 Windows 机器码绑定，不能复制到其他电脑使用。
- 到期后代理服务会停止接受语言、图片、视频和上传请求。
- 更换电脑或重装系统导致机器码变化时，需要重新申请授权。

四、数据安全
API Key 和配置保存在客户端目录的 config.json 中。请勿将自己的 config.json 发送给其他人。
自动配置洛水：
1. 在外接软件中配置并保存语言、图片、视频模型。
2. 保持底部“自动配置洛水外接接口”勾选；外接软件启动时即会写入配置。
3. 点击“启动洛水”，软件会保存当前设置、预检语言密钥并启动洛水。
4. 若提示“语言密钥无效”，请更换语言模型 API Key；洛水不会带着错误密钥继续启动。
5. 首次修改会备份 data/settings.json.bak_external_proxy。
6. 软件会自动安装推理请求重定向补丁；已有 sitecustomize.py 会先备份。
7. 软件会备份并配置 run.py，启动后自动确认补丁是否真正加载。
8. 启动前会真实请求一次所选语言模型；不是只检查模型列表。
9. 长推理自动使用上游流式传输并在本地聚合，避免 HTTP 524 超时。
10. 视频多参考图会自动转换为中转站识别的 images 数组，不需要用户填写 JSON。
11. 日志中同一条 VIDEO submitted 记录的 upstream_task 和 references 数量，代表该视频任务实际提交的参考图。
12. 详细日志会显示图床上传、视频提交、排队、生成进度、失败详情和视频文件回传阶段。

五、自动更新
1. 软件启动时自动检查公开版本清单，也可以点击“检查更新”。
2. 发现新版本后点击确认，软件会打开 GitHub/CDN 下载地址。
3. 关闭旧版本后，用新发行包中的客户端替换旧文件；授权文件和 config.json 请保留。
