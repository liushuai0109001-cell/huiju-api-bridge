# 授权签发说明

`授权管理` 目录仅由软件发行方保管，绝对不能放入客户发行包。

## 签发授权

1. 双击 `授权签发工具.exe`。
2. 填写客户机器码、客户名称和授权有效天数。
3. 点击“生成授权”。
4. 点击“复制授权码”发送给客户，或打开 `已签发授权` 目录发送自动保存的授权码文件。

工具读取同目录的 `license_private.key`。客户将授权码粘贴到客户端“授权管理”页并点击“激活授权”。

## 安全要求

- `license_private.key` 是唯一签发私钥，必须离线备份并严格保密。
- `license_public.key` 可以用于编译客户端，不能单独用于签发授权。
- 不要重新生成或替换密钥。更换密钥后，旧客户端和旧授权码将无法继续匹配。
- 客户发行包中只能包含客户端程序和公开说明，不能包含整个 `授权管理` 目录。
